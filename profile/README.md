# eduTAP Collective - The Collection of non Core-Packages of eduTAP Components and Libraries to build an eduTAP Service.

eduTAP is a Project to digitalizize the Campus cards and Student IDs / Staff IDs of Higher Education Insitutions.

eduTAP Software is categorizied into two major domains:

* [eduTAP Core](https://github.com/edutap-eu/) --> Core Libraries to create and manage Wallet Passes
* [eduTAP Collective](https://github.com/edutap-collective) --> Non Core Libraries that help to build an eduTAP Service.
